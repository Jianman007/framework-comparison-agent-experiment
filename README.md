# Framework Comparison Experiment

A comparative experiment on different LLM agent frameworks for automated weekly project report generation.

## Objective

This project compares several agent frameworks:

- LangGraph
- AutoGen
- CrewAI
- MetaGPT

The experiment evaluates their performance on the same task:

Generate a professional weekly project report from raw project updates.

## Frameworks Compared

| Framework | Architecture |
|---|---|
| LangGraph | Graph-based workflow |
| AutoGen | Message-based multi-agent |
| CrewAI | Role-based multi-agent |
| MetaGPT | Role/Action-based workflow |

## Evaluation Metrics

The frameworks are compared using:

- Runtime
- Token Consumption
- Code Lines (LOC)
- Output Quality
